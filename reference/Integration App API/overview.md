# Integration App API Overview

The Integration App API provides a comprehensive set of endpoints for managing integrations, connections, and various components of the integration platform.

This API documentation is organized into the following main sections:

## Apps
Manage integrations and connections between applications.

## Integration Builder
Build and configure integration components including scenarios, actions, flows, field mappings, data sources, data links, app data schemas, app events, API operations, data collections, and proxy API.

## Customers
Manage customer accounts and related information.

## Activity Log
Monitor and manage flow runs, external event logs, app event logs, external event pulls, incoming webhooks, and external API logs.

Each section contains detailed endpoints for creating, reading, updating, and deleting resources.

# Proxy API

The Proxy API allows you to make requests to external APIs through the Integration App platform. This provides several benefits:

1. **Authentication Handling**: The platform manages authentication tokens and credentials
2. **Rate Limiting**: Automatic handling of rate limits and retries
3. **Logging**: All API calls are logged for debugging and audit purposes
4. **Transformation**: Request and response data can be transformed as needed

## Using the Proxy API

To use the Proxy API, you need to configure the appropriate connection and then make requests through the platform's proxy endpoints. The platform will handle authentication, logging, and other aspects of the API interaction.

Refer to the Connection-level API Operations section for details on how to interact with specific operations through the proxy.
